Different video platforms handle seeking differently — some jump 5 seconds at a time, others 10, and many don't support keyboard controls at all. QuickSeek for Videos brings a consistent, customizable seeking experience to every video site. Simply press the arrow keys (← →) to skip forward or backward by your preferred duration.

## Features

**Shortcuts**

| Key | Action |
| --- | --- |
| ← → | Skip backward / forward; hold to keep seeking |
| 0 – 9 | Jump to 0% – 90% of the video |
| Space | Play / pause |

- On-screen overlay shows the action plus current time / duration
- Customize skip duration from 1 to 60 seconds — via slider, ± buttons, presets (2s / 5s / 10s / 15s / 30s), or direct input
- **Frame mode**: arrow keys step one frame at a time, using the video's measured frame rate
- **Per-site control**: turn the extension off for the current site, or disable arrows / digits / space individually
- Works on any site with an HTML5 `<video>` element, including embedded players (e.g. YouTube embedded in an article)
- Settings take effect immediately — no page refresh required

## Installation

**Chrome Web Store (Recommended)** — Search for **QuickSeek for Videos**.

**Load Unpacked:**

1. Download and unzip this repo
2. Open `chrome://extensions` (Edge: `edge://extensions`)
3. Enable **Developer mode** in the top-right corner
4. Click **Load unpacked** and select the project folder

## Usage

1. Open any video page
2. Click the toolbar icon to set your skip duration, or click a glowing key on the keyboard to toggle that shortcut
3. Press **← →**, **0–9** or **Space** to control the video
