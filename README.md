不同视频网站的快进/快退规则各不相同：有的每次跳转 5 秒，有的跳转 10 秒，还有许多网站根本不支持键盘控制。QuickSeek for Videos 为所有视频网站带来统一且可自定义的跳转体验，安装后只需按方向键（← →）即可按照你预设的时长快速跳转。

## 功能

**快捷键**

| 按键 | 作用 |
| --- | --- |
| ← → | 快退 / 快进，按住连续跳转 |
| 0 ～ 9 | 跳转至视频 0% ～ 90% 位置 |
| 空格 | 播放 / 暂停 |

- 操作时在视频上显示提示（跳转量 + 当前时间 / 总时长）
- 跳转时长 1 ～ 60 秒自定义，支持滑块、± 按钮、预设按钮（2s / 5s / 10s / 15s / 30s）、直接输入数字
- **逐帧模式**：方向键每次前进 / 后退一帧，帧长根据视频实际帧率测量
- **按网站开关**：可在当前网站整体关闭插件，或单独关闭方向键 / 数字键 / 空格
- 支持所有含 `<video>` 标签的网站，包括网页中嵌入的播放器（如文章内嵌的 YouTube）
- 设置实时生效，无需刷新页面

## 安装

**Chrome 应用商店（推荐）** — 搜索 **QuickSeek for Videos** 安装。
https://chromewebstore.google.com/detail/fihlcdlonopbcfbjcabobabggdbapoah?utm_source=item-share-cb

**手动加载：**

1. 下载并解压本仓库
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 开启右上角「**开发者模式**」
4. 点击「**加载已解压的扩展程序**」，选择项目文件夹

## 使用

1. 打开任意视频页面
2. 点击工具栏图标调整跳转秒数，或点击键盘图上发光的按键开关对应功能
3. 直接按 **← →**、**0～9**、**空格** 控制视频
